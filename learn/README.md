# 学习文档

纯静态页面，入口为 `/learn/`。根目录 `index.html` 的导航和学习卡片链接到这里；直接由 GitHub Pages 托管，不需要构建或后台。

本地预览：在仓库根目录运行 `python -m http.server 4177 --bind 127.0.0.1`，打开 `http://127.0.0.1:4177/learn/`。不要直接双击 HTML：文章使用 HTTP fetch 加载。

## 添加文章

1. 在 `articles/` 添加 UTF-8 Markdown 文件，例如 `new-topic.md`。正文从 `##` 开始，页面标题来自目录。
2. 在 `articles.json` 增加对应 id、标题、摘要、分类、关键词和关联文章 id。分类为 `basics` 或 `practice`；阅读时间由正文自动计算，不填写固定分钟数。
3. 正文使用 `[另一篇文章](?article=other-id)` 关联，`related` 提供文末延伸阅读。独立链接使用 `/learn/?article=new-topic`，章节链接使用页面生成的 `#section-N`。
4. 正文支持标准 Markdown 标题、列表、引用、链接、表格和代码块。原始 HTML 转义，不执行；Markdown 图片目前只显示替代文字，插图使用受控的交互模块。
5. 系列文章填写 `series`（系列名称）、`seriesOrder`（从 1 开始的顺序）和可选的 `seriesLabel`（短标题）。同系列文章自动在正文前显示推荐阅读顺序，当前文章有明确标记；非系列文章不显示。

写作使用直接的说明语气，先解释定义，再说明原理、参数影响和适用条件。避免故事化比喻、鼓励式文案和“来算一笔账”等表达，保留具体计算、必要术语解释和引用来源。

当前六篇按单篇约半小时的系统入门深度编写：照片与像素 → 相机拍摄 → 视频基础 → 视频压缩 → OBS 参数 → 后期处理。每篇至少 6,000 个阅读单位，包含原理、条件、实际场景和排查方法。一个汉字或一个英文词/数字计为一个单位，排除代码块和链接地址，按每分钟 200 单位向上取整；这只是说明性估算，不保证个人阅读时长。手机目录默认收起，可展开跳转。

交互实验放入特殊代码块：开头是三个反引号加 `demo`，内容写一个名称，末尾用三个反引号关闭。可用 `frames`（帧率）、`pixels`（像素及 RGB）、`compression`（量化示意）、`gop`（I/P/B 帧）、`bitrate`（数据量估算），以及 `decision:主题-序号`（情境判断）。允许的判断内容统一定义在 `labs.js`，不执行 Markdown 中的任意代码。它仍是合法 Markdown，在其他阅读器中会显示实验名称。每篇已发布文章至少包含五个可操作模块。

搜索在浏览器中索引全部文章标题、摘要、标签与 Markdown 正文，不上传搜索词；空格分隔的词需要同时匹配。正文加载失败时显示状态，阅读页可以重试。动画支持暂停并遵循系统减少动态效果偏好。

## 文件

- `index.html` / `style.css`：图书馆、阅读布局、手机适配。
- `app.js`：目录、全文搜索、路由、目录及关联阅读。
- `reading.mjs`：根据实际 Markdown 正文估算长度与阅读时间。
- `markdown.js`：Markdown 渲染边界，转义 HTML、限制链接协议和交互模块名称。
- `labs.js`：Canvas 原理动画与计算器。所有图形本地绘制；示意与实际编码的区别标注在实验下方。
- `theme.js`：浅色、深色、护眼主题，以及背景、文字、强调色自定义。保存在 `gao-learn-appearance-v1`；存储不可用时仍允许当次使用，正文颜色会做最低对比度调整。照片和颜色样本保留其本来的颜色，控件和说明随主题变化。
- `articles.json` / `articles/*.md`：文章元数据与正文。文章内附一手资料链接。
- `vendor/marked.esm.js`：Marked 17.0.3 的原始 npm 发行文件；许可证保留在 `vendor/marked.LICENSE.md`。本地托管，运行时不请求 CDN。

文章数量由目录自动更新。页面不记录阅读进度，也没有账号依赖。

验证：仓库根目录运行 `node --test learn/tests.mjs`，检查 Markdown 安全边界、文章链接、目录锚点、系列顺序及主题设置的异常恢复。交互、手机布局、主题切换和持久化需通过浏览器检查。
